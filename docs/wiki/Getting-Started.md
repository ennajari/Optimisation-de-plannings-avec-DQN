# Getting Started with Optimisation-de-plannings-avec-DQN

## 📋 Prerequisites
- **Python** 3.10+ / **Node.js** 18+
- **Git** & **GitHub CLI**

## ⚡ Quick Start
```bash
# Clone the project repository
git clone https://github.com/ennajari/Optimisation-de-plannings-avec-DQN.git
cd Optimisation-de-plannings-avec-DQN

# Run the evaluation harness
python scripts/eval_harness.py

# Run the QA test suite
python -m pytest tests/test_monitoring_and_qa.py
```
